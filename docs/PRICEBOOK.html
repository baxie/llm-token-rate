解释与边界

MTok = 100 万 Token。Cursor 的 selected-model 口径是 API list-price pass-through，是否可选须以其当日模型选择器为准。Kiro 的 Credit 倍率作用于随任务复杂度变化的基础 Credits；Windsurf 以每条用户 Prompt 的模型倍率计费；Cline 没有公开的固定平台倍率。Copilot 的模型级用量为 $0.01 / AI Credit 的 Token 价折算。已停止的模型与产品不在本报告保留。
